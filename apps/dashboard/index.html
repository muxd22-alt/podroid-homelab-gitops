Passwords & secrets

  • Nothing secret is stored in this repo or on this page.
  • Gogs & Jellyfin: passwords are created in their first-run wizards.
  • Fladder: uses your Jellyfin login.
  • SiYuan: access code lives only in apps/siyuan/.env (gitignored).
  • Per-app settings: copy each apps/<name>/.env.example → .env (the installer already did this).

Domains

  • muxd1.com…muxd5.com and muxd.local are mapped to 127.0.0.1 in the VM's /etc/hosts by the installer.
  • Opening the dashboard from your phone? Links already adapt to the host you used.
  • Ports are registered with podroid-forward automatically when available.

Operations

  • homelab sync — pull & deploy now  ·  homelab status — overview  ·  homelab logs <app> — container logs
  • Every 12h the updater syncs main, redeploys changed apps, healthchecks, and rolls back on failure.
  • New services: open a GitHub issue with the New app request template — CI opens a PR.
